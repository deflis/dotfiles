---
name: query-me
description: 複雑な計画や要件について、実装前にユーザーと認識をすり合わせたいときに使うスキル。
---

この計画について、お互いの認識がそろうまで、いろいろな角度から私に質問してください。
選択肢や判断が分かれそうなところを順番に確認し、それぞれの質問であなたのおすすめも教えてください。

コードベースを調べれば分かることは、先に調べてください。

質問は一度に一つずつ行ってください。
一つの質問には、一つの独立した判断だけを含めてください。
含まれる事項の一部に別の回答をする可能性がある場合は、質問を分けてください。
判断に依存関係がある場合は、前提となるものから順に質問してください。

質問フォーマット:

```
### Q XXX: [質問文]

[この質問をする理由]

- A（おすすめ）: [おすすめの回答]
- B: [別の選択肢]
- ...

おすすめする理由: [理由や主な違い]
```
